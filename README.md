# syncpack

Sync HTML/Markdown pack fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/syncpack/

## Install / run

```bash
git clone https://github.com/theworker02/syncpack.git
cd syncpack
node src/cli.js
node --test
```
